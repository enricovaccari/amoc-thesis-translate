# Living Atlantic — amoc-thesis-translate

Condition **C3** of the MSc thesis *Making the Invisible Intelligible*: an
experiential descent, in five scenes, from the Greenland surface into the
latent space of the AMOC. Research artefact, not a product (§1.8).

**Design criterion (Ch. 7):** every perceivable element must be traceable to
a field of `amoc_translate_bundle.json` and defensible with a citation.

## Run

```bash
npm install
npm run dev        # → http://localhost:5173
```

## Build order (risk-first, not narrative-first)

1. **Scena III** — the data engine every scene reuses. *(done: this scaffold)*
2. **Scena V** — DP2.2, the thesis's design contribution. Ensemble spread →
   particle dispersion + timbral roughness (`heartbeat.setRoughness`).
3. **Scena IV** — camera dwell + beat suppression on the 2009–2010 cluster.
4. **Scena II** — profile reconstruction `mean + pc1·eof1 + pc2·eof2`.
5. **Scena I** — pure narrative, cheapest, last.
